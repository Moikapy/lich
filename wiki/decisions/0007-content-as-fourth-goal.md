# 0007: Content creation as a vertical (framing superseded)

## Context

[[roadmap-issues]] (#113) framed Lich around three game goals: code games, play games, and live inside games. Addendum 4 widened that to include **create media content** (YouTube / Shorts, clipping, art).

## Decision (historical)

Accept **#113 Addendum 4**: treat **(D) Create content** as an explicit vertical beside games (A/B/C), sharing one harness; park media toolchains under #114 item 11.

## Supersession

**#113 Addendum 5** / [[0008-idea-agnostic-extensible-harness]] reframes product identity: Lich is an **idea-agnostic** harness that wins on user control (plugins, tools, profiles). Content and games remain **valid dogfood verticals**; they are no longer co-equal definitions of the product.

The practical guidance below still holds under 0008.

## Consequences (still applicable)

- Do not read the roadmap as “Godot/NPC only.”
- Phase 6 multimodal serves play **and** content.
- Studio work uses a **dev/studio** profile, not [[embedded-safety-profile]].
- Media toolchains stay deferred (#114 item 11) until content blocks + a studio Profile exist.

## Alternatives considered

See the original Addendum 4 discussion; superseded alternatives are recorded on [[0008-idea-agnostic-extensible-harness]].
